통화분석 APK — 설치·사용 안내 (v3)

[설치]
 1. 이전 버전(v2)이 있으면 먼저 삭제 (서명키가 바뀌어 덮어쓰기 불가)
 2. https://github.com/archssue-design/callagent/releases 최신 항목의 CallAgent.apk 다운로드 → 설치
    (이후 버전부터는 삭제 없이 덮어쓰기 설치 가능)

[설정 — 앱 화면 순서대로]
 1. 모든 파일 접근 권한 허용
 2. 배터리 최적화 제외
 3. Groq API 키 붙여넣기 (무료·카드 불필요: 폰 브라우저 console.groq.com/keys → Create API Key → gsk_…)
 4. "키 테스트 후 자동감시 시작" → "키 정상. 자동감시 시작됨" 토스트
 5. 삼성 설정 > 배터리 > 백그라운드 사용 제한 > 절전 예외 앱 → 통화분석 추가

[동작]
 - 설치 이후 녹음만 분석함 (설치 이전 녹음은 "설치 이전 녹음파일도 분석" 체크 시에만)
 - 15분 간격 자동 스캔. 즉시 확인은 통화 종료 90초 후 "지금 스캔"
 - 화면 상단 상태창에 권한·키·감시 상태·최근 오류, 하단에 로그 표시
 - 무료 한도 초과(429)·네트워크 오류는 자동으로 10분 후 재시도(최대 5회). 키 오류 등은 알림으로 표시
 - 매일 08:00 이후 첫 스캔 때 일일 업무목록 알림
 - 원본 녹음파일은 읽기만 함. 삭제·수정 없음

[고급 설정]
 - STT/분석을 OpenAI·Claude로 바꿀 수 있음 (해당 키 입력 후 "고급 설정 저장")
 - 카카오톡 나와의채팅: REST API 키·refresh_token 입력 + 체크 후 저장
